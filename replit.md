# Strategy Engine

Client onboarding tool that takes a minimal client brief (name, website, Instagram, one-line description) and produces both a structured brand strategy (stored as JSON) and a polished narrative strategy document (Markdown) the client can read, edit, approve, and export to PDF.

## Architecture

Monorepo (pnpm workspaces) with three artifacts:

- **`artifacts/strategy-engine`** — React + Vite frontend at `/`. Editorial-calm visual identity (serif headlines, warm off-white, deep terracotta). Pages: dashboard (`/`) and workspace (`/clients/:id`).
- **`artifacts/api-server`** — Express API at `/api`. Routes in `src/routes/clients.ts`. Strategy pipeline in `src/lib/strategy/` (`enrich.ts`, `templates.ts`, `generate.ts`).
- **`artifacts/mockup-sandbox`** — design canvas (unused for this build).

Shared libs:
- `lib/db` — Drizzle schema + Postgres client. Tables: `clients`, `onboarding_profiles`, `strategies` (versioned, jsonb fields).
- `lib/api-spec` — OpenAPI spec.
- `lib/api-zod`, `lib/api-client-react` — generated by Orval.

## Strategy pipeline

`POST /api/clients/:id/strategy/generate` runs three OpenAI calls (gpt-5.2, via the Replit AI integration proxy — no key needed; uses `AI_INTEGRATIONS_OPENAI_*` env vars):

1. **Enrich** (`enrich.ts`) — infers a rich brand profile from the four onboarding fields (offer, price band, business model, audience, tone, positioning, platform, competitors). Stored on `onboarding_profiles.enriched_data`.
2. **Structured strategy** (`generate.ts → generateStructuredStrategy`) — JSON object with 12 sections: market_narrative, problem_gap_solution, brand_foundation, brand_philosophy, audience, emotional_drivers, platform_strategy, content_strategy, kpis, tracking_plan, phases, asset_requirements.
3. **Strategy document** (`generate.ts → generateStrategyDocument`) — long-form Markdown, paragraph-led, 1200–2000 words, written in the voice prescribed by the chosen template.

Each generation creates a new versioned row in `strategies` (status `draft`).

## Templates

Defined in `lib/strategy/templates.ts`:

- `performance_marketing` — metrics-driven, channel economics, ROAS focus
- `brand_building` — narrative-led, long-term equity, owned/earned
- `personal_brand` — first-person, POV-driven, authority-building
- `d2c_growth` — operator-minded, AOV/LTV, creator-led
- `auto` — selector picks based on enriched `business_model` + `positioning`

UI exposes a dropdown (auto / 4 templates) on the workspace page.

## Frontend behaviors

- **Dashboard**: card grid of clients with status badges, "+ New Client" dialog (4 fields, navigates to workspace on create).
- **Workspace**:
  - No strategy → onboarding profile + Generate panel (template select).
  - Generating → rotating loader stages (15–30s).
  - Has strategy → sticky header with version, status, template, action buttons (Edit / Regenerate / Approve / Print-PDF). Markdown rendered with `marked` in `prose` typography (~70ch). Side accordion shows the structured strategy.
  - Edit mode: side-by-side textareas for the doc (Markdown) and the structured strategy (JSON, validated on save).
  - Print: `@media print` rules in `index.css` hide sticky header and side panel; `window.print()` produces clean PDF.

## Constraints

- No emojis in UI.
- All API hooks imported from `@workspace/api-client-react`.
- Markdown content from the model is trusted (we generate it). Rendered via `marked.parse(..., { async: false })` into `dangerouslySetInnerHTML`.
