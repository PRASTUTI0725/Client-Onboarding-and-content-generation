# TASK: Build Content Planner + Calendar System (Strategy-Driven, UI-First)

We are building a system that converts strategy into a fully usable content calendar.

This is NOT a manual planner.
This is NOT a document.
This is a visual, pre-filled calendar like Buffer/Notion.

---

# 1. INPUT

Use strategy output:

* content_strategy.pillars
* audience
* goal
* platform_strategy
* phases

---

}

* Align posts with:

  * distribution %
  * weekly flow
  * strategy goals

* Ensure:

  * pillar balance
  * format variation
  * clear CTA per post

* Do NOT generate generic ideas

# 4. UI (MOST IMPORTANT)

We are building a CALENDAR-FIRST INTERFACE.

---

## DEFAULT VIEW:

* Monthly calendar grid
* Pre-filled posts
* No empty states

---

## EACH CALENDAR CARD:

Display:

* Format (Reel / Carousel)
* Pillar (color-coded)
* Short hook/title
* Status (Draft / Approved / Scheduled)

---

## INTERACTIONS:

* Click → open side panel
* Drag → reschedule

---

* Status
